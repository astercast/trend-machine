How to read this wire

Live means the lane's stored file was written by the latest refresh and holds hits. Degraded means the file was rewritten and holds zero — the lane ran and recorded nothing (the Reddit direct-JSON lane lives here: Reddit's public JSON is often 403 from datacenters, and the RSS lane carries Reddit instead). Stale · skip means the latest refresh did not rewrite the file at all — the fetcher's skip path writes nothing — so its hits are shown with their real date and excluded from the current total (the YouTube Invidious/direct lane; channel RSS carries YouTube). Skip by design is TikTok and X: no vetted keyless TikTok source exists, and X needs a bearer token that is not set — both lanes are documented in PIPELINE.md and neither one's data is ever faked.

Every number on this page traces to a file named in the payload's provenance (data/v1/live-wire.json, built by scripts/build_live_wire.js). Movers come from the stored velocity history merged with the resolution archive — the same merge rule the Oracle Board uses — and flat topics are counted in the banner, not hidden.
