API docs

Everything is static JSON under api/v1/ — no auth, no keys, no rate limits. Start at the manifest: every endpoint with its description, schema URL, updated timestamp, and record counts. Schemas are draft-07 under api/v1/schema/. The full agent guide (workflows included) is AGENT.md; shared conventions are in API.md.

EndpointWhat it isSchema
api/v1/trends.jsonAll topics, full dossiers — sort by opportunity_score desc for the hottest plays; each topic now carries trend_type (format/topic/format+topic) and seeded verification flagsapi/v1/schema/trends.json

Try the API

Pick an endpoint and fetch it live from this page. Everything runs client-side; large payloads are pretty-printed and truncated for display.













One query that matters


curl -s https://<host>/api/v1/trends.json \
 | python3 -c "
import json,sys
d = json.load(sys.stdin)
for t in sorted(d['topics'], key=lambda t: t['opportunity_score'], reverse=True)[:5]:
    if not t.get('stale'):
        print(t['opportunity_score'], t['title'], '|', ' '.join(t['hashtags'][:3]))
"
